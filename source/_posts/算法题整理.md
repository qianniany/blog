## 1\.线性dp

### （1）[数位翻转](https://www.lanqiao.cn/problems/20145/learning/)

```C++
#define _CRT_SECURE_NO_WARNINGS
#include <stdlib.h>
#include <string.h>
#include <stdio.h>
#include <math.h>
int arr[1010];
long long dp[1010][1010][2];
long long max(long long x,long long y) {
  return x > y ? x : y;
}
int reserve(int x) {
  int sum = 0;
  int cnt = 0;
  while (x > 0) {
    sum = sum * 2 + x % 2;
    x /= 2;
  }
  return sum;
}
int main() {
  int n;
  int m;
  long long sum = 0;
  scanf("%d %d", &n, &m);
  for (int i = 1; i <= n; i++) {
    int x;
    scanf("%d", &x);
    arr[i] = reserve(x) - x;
    sum += x;
  }
  for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
      dp[i][j][0] = max(dp[i-1][j][0],dp[i-1][j][1]);
      dp[i][j][1] = max(dp[i - 1][j][1],dp[i - 1][j - 1][0]) + arr[i];
    }
  }
  long long a = 0;
  for (int i = 1; i <= m; i++) {
    a = max(a, max(dp[n][i][0],dp[n][i][1]));
  }
  printf("%lld", a + sum);
}
```

1\.首先先通过短除法写一个将十进制转为二进制，再将倒转的二进制转为十进制的方法

2\.然后再用倒转的数与原数做减法求出一个贡献数列，方便之后区域选择和dp

3\.p数组需要设置三维,因为不知道最后一个数是否被选中，通过\[1\]表示选中，\[0\]表示没选中，以方便之后dp动态转移方程的建立

动态转移方程

dp\[i\]\[j\]\[0\] = max\(dp\[i\-1\]\[j\]\[0\],dp\[i\-1\]\[j\]\[1\]\); 若不选最后一个数
dp\[i\]\[j\]\[1\] = max\(dp\[i \- 1\]\[j\]\[1\],dp\[i \- 1\]\[j \- 1\]\[0\]\) \+ arr\[i\]; 若选择最后一个数

## 2\.树状dp

树状动态规划（Tree DP）是一种在树形结构上解决动态规划问题的技巧，常用于解决涉及树的最优子结构问题。它通过递归地计算每个节点的状态值，从而得到整棵树的最优解。

### （1） [Edge Groups](https://vjudge.net/problem/Gym-103446G)

```C++
#define _CRT_SECURE_NO_WARNINGS
#include<bits/stdc++.h>
using namespace std;
#define ll long long
#define mod 998244353
vector<ll> v[100010];
ll arr[100010];
ll dp[100010];
ll s[100010];
void dfs(ll a,ll b) {
        s[a] = 1;//当前根下结点总数量
        dp[a] = 1;//方法数
        ll cnt = 0;//奇数子节点的shulinag
        for (auto& x : v[a]) {
                if (x == b) {//因为初始化图时是双向的，所以要防止又回溯到根结点导致无限循环
                        continue;
                }
                dfs(x, a);
                s[a] += s[x];
                if (s[x] & 1) {
                        cnt++;
                }
                dp[a] = dp[a] * dp[x] % mod;
        }
        if (cnt & 1) {
                cnt++;
        }
        dp[a] = dp[a] * arr[cnt] % mod;
}
int main(){
        ll t;
        scanf("%lld", &t);
        for (ll i = 1; i <= t - 1; i++) {
                ll a, b;
                scanf("%lld %lld", &a, &b);
                v[a].push_back(b);
                v[b].push_back(a);
        }
        //初始化一下需要使用的公式
        arr[0] = 1;
        //偶数个数两两组合的总方法数（为什么是偶数，因为只用了偶数个数）
        for(ll i = 2; i <= t; i+=2){
                arr[i] = arr[i - 2] * (i - 1) % mod;
        }
        dfs(1,0);
        printf("%lld", dp[1] % mod);
        return 0;
}
```

第一次见到这种类型的dp,感觉挺新奇的

题意:

给n个结点\(n\>=3 且n为偶数\)，确保这n个节点之间有n\-1条边，即这n个结点连通，形成一个树形结构。

要求将两个边分成一组，两条边必须有一个公共的顶点才可分为一组，问一共有几种分组方式。

思路：

假设任取一个结点作为一个根节点，根节点下有x个子节点

根节点的分组数量首先肯定要先将x个子节点的分组数量相乘，之后再考虑子节点之间的分组

若子节点本身的总结点数为奇数，则它本身就已经分好了组，不用再与其它子节点的多余边相拼

若子节点总结点数为奇数，则它一定会多于一条边无法分组，而多的这条边就可以与其它子节点总数为奇数多余的边相拼

所以最后还要乘个子节点总数为奇数的结点两两组合的所有种类数

f\[子\] = f\[子 \- 2\] \*（n\-1）\(子为偶数\)

若子节点总数为奇数的结点数也为奇数个，则最后会多一条边，应与父节点的父节点的那条边相组合

f\[子\+1\] = f\[子\+1 \- 2\] \*（n\-1）\(子为奇数\)

2\.合并

正常合并即直接让一个树的根结点指向另一个树的根结点即可

按秩合并优化:

秩指树的结点数或高度

\(1\)比较树的高度，让高度小的合并到高度高的树

\(2\)比较结点数量，让结点数少的合并到结点数多的树

按秩合并也被称为*启发式合并*。它是数据结构相关问题的一种重要思想，就是把“小的结构”合并到“大的结构”中，并且只增加“小的结构”的查询代价。所以在并查集中，我们把所有集合合并起来后，增加的总代价也不会超过*N*log*N*。也就是说，单次查询的平均时间复杂度为O\(log*N*\)。

同时使用路径压缩和按秩合并的优化单次查询操作的时间复杂度会变成：O\(_α_\(_N_\)\)。其中*α*\(_N_\)为反阿克曼函数，它是一个比log*N*增长得还要慢的函数。对于∀*N*≤221019279，都有*α*\(_N_\)≤5。可以把O\(_α_\(_N_\)\)理解为常数级时间复杂度

## 3\.线段树

### [P3372 【模板】线段树 1](https://www.luogu.com.cn/problem/P3372#submit)

```Bash
#define _CRT_SECURE_NO_WARNINGS
#include<bits/stdc++.h>
#define int long long
using namespace std;
int a[100010<<2];
int ans[100010 << 2];
int tag[100010 << 2];
void build(int p,int l,int r) {
        if (l == r) {
                ans[p] = a[l];
                return;
        }
        int mid = (l + r) / 2;
        build(p << 1, l, mid);
        build(p << 1 |1, mid + 1, r);
        ans[p] = ans[p << 1] + ans[p << 1 |1];//左右移优先级小于+-
}
void f(int p,int l,int r,int k) {
        ans[p] += (r - l + 1) * k;
        tag[p] += k;
}
void push_down(int p,int l , int r,int k){
        int mid = (l + r) / 2;
        f(p << 1, l, mid,k);
        f(p << 1 |1, mid + 1, r,k);
        tag[p] = 0;
}
void update(int l,int r,int l1,int r1, int k,int p){
        if (l1 <= l && r1 >= r) {
                ans[p] += (r - l + 1) * k;
                tag[p] += k;
                return;
        }
        push_down(p,l,r,tag[p]);
        int mid = (l + r) >> 1;
        if (l1 <= mid)update(l,mid,l1,r1,k, p << 1);
        if (r1 > mid) update(mid + 1,r,l1,r1,k, p << 1 | 1);
        ans[p] = ans[p << 1] + ans[p << 1 |1];
}
int query(int l, int r, int l1, int r1, int p) {
        int sum = 0;
        if (l1 <= l && r1 >= r) {
                return ans[p];
        }
        push_down(p, l, r, tag[p]);
        int mid = (l + r) >> 1;
        if (l1 <= mid)sum+= query(l, mid, l1, r1,p<<1);
        if (r1 > mid) sum+= query(mid + 1, r, l1, r1,p<<1|1);
        return sum;
}
signed main()
{
        int n;
        int m;
        scanf("%lld %lld", &n, &m);
        for (int i = 1; i <= n; i++) {
                scanf("%lld",&a[i]);
        }
        build(1,1,n);
        for (int i = 1; i <= m; i++) {
                int x;
                scanf("%lld", &x);
                if (x == 1) {
                        int l, r, k;
                        scanf("%lld %lld %lld", &l, &r, &k);
                        update(1,n,l,r,k,1);
                }
                else {
                        int l, r;
                        scanf("%lld %lld", &l, &r);
                        printf("%lld\n",query(1, n, l, r, 1));
                }
        }
}
```

线段树也是一种对区间内的数进行操作的一种树形结构，它可以与差分相类比

线段树查询时间复杂度:O\(log\(n\)\)

修改时间复杂度:O\(log\(n\)\)

差分查询时间复杂度:O\(n\)

修改时间复杂度:O\(1\)

所以，若多次修改，少量查询则用差分，否则都可以用线段树,除非区间大小超过\(10e7\),此时线段树创建会消耗大量内存，所以改用差分

**建立**

每次找寻中间数，以mid为中心划分区间，向下递归父节点\(x\)的左右孩子分别为2x和2x\+1,直到找到区间l==r处,给存储线段树的数组赋值

ans\[p\] = ans\[p \<\< 1\] \+ ans\[p \<\< 1 \|1\]

在通过上面这串式子，实现回溯，即给父节点赋值，一直回溯到根结点，以此完成线段树的构建

```Bash
void build(int p,int l,int r) {
        if (l == r) {
                ans[p] = a[l];
                return;
        }
        int mid = (l + r) / 2;
        build(p << 1, l, mid);
        build(p << 1 |1, mid + 1, r);
        ans[p] = ans[p << 1] + ans[p << 1 |1];
}
void f(int p,int l,int r,int k) {
        ans[p] += (r - l + 1) * k;
        tag[p] += k;//注意一定不要写成等于号，因为可能原来也存在标记

        f(p << 1, l, mid,k);
        f(p << 1 |1, mid + 1, r,k);
        tag[p] = 0;
```

**修改**

下面代码是指给区间l1，r1增加k

更新操作也是需要向下递归，寻找线段树区间在l1\-r1内的区间，寻找到区间后，更新此区间的值，并给此区间进行一次懒标记

懒标记就是指先不给下面的区间进行修改处理，等到查询到下面区间后，再对下面区间进行修改，此操作使修改的时间复杂度趋向于O\(log\(n\)\)

若修改途中遇到了加有懒标记的区间，也要进行懒标记下发处理，即下面函数push_down\(\)；


[215\. 数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

```Java
class Solution {
public:
    int quickSort(vector<int>& nums, int l,int r,int k){
        int temp = nums[l];
        int i = l;
        int j = r;
        while(i < j){
            while(nums[j] >= temp && i != j){
                j--;
            }
            nums[i] = nums[j];
            while(nums[i] <= temp && i != j){
                i++;
            }
            nums[j] = nums[i];
        }
        nums[i] = temp;
        if(i == k){
            return temp;
        } else {
            if(i > k){
                return quickSort(nums,l,i - 1,k);
            } else {
                return quickSort(nums,i + 1,r,k);
            }
        }
    }
    int findKthLargest(vector<int>& nums, int k) {
        return quickSort(nums,0,nums.size()-1,nums.size()-k);
    }
};
```

**1\.三数取中选择基准**

原算法固定用左端点作为基准，在有序数组中会导致每次分区仅减少 1 个元素，触发 O \(n²\) 复杂度。

三数取中通过比较左、中、右三个位置的元素，选择中间值作为基准，大幅降低了极端不平衡的概率，使最坏情况更难发生。

若追求更简单的实现，也可改用**随机选择基准**（如int pivotIdx = l \+ rand\(\) % \(r \- l \+ 1\);），效果类似。

```C++
int medianOfThree(vector<int>& nums, int l, int r) {
        int mid = l + (r - l) / 2;
        // 排序左、中、右三个元素
        if (nums[l] > nums[mid]) swap(nums[l], nums[mid]);
        if (nums[l] > nums[r]) swap(nums[l], nums[r]);
        if (nums[mid] > nums[r]) swap(nums[mid], nums[r]);
        swap(nums[mid], nums[l]);
        return nums[l];
    }
```

# 五\.快速幂

## 1\.[P1226 【模板】快速幂](https://www.luogu.com.cn/problem/P1226)

求a^b%p的值

暴力相乘的话，电脑要计算 _b_ 次，并且可能会出现大小越界的风险；

用快速幂，计算次数在 *log*2\(_b_\) 级别，并且能规避以上风险。

```C++
#define _CRT_SECURE_NO_WARNINGS
#include<stdio.h>
int main() {
    long long sum = 1;
    long long a, b, p;
    scanf("%lld %lld %lld", &a, &b, &p);
    int x = a;
    int y = b;
    int z = p;
    while (b > 0) {
        if (b & 1) {
            sum = sum * a % p;
        }
        a = a * a % p;
        b >>= 1;
    }
    printf("%lld^%lld mod %lld=%lld",x,y,z,sum % p);
}
```

例如10进制b=11化为2进制为1011。

就可以说a^11 = a^8 \* a^2 \* a^1。

所以快速幂的关键就是把指数拆成二进制逐步相乘

就拿a=2,b=11来说

首先看循环if\(b\&1\)这一步,这一步是为了取出转为二进制b的最后一位元素。（只能为0或者1）

若为1,的话则用整个数sum\*a

a初始表示的是二进制的第一位即a^1，第二位则是a\*a=a^2,以此类推，所以每次if条件之后 需要将a变成下一位，

之后将二进制b右移一位，准备取下一位。

至于后面为什么都要加上%p可以看看如下公式

**\(\*\*\***A**\***\+**\***B**\***\)mod**\***b**\***=\(**\***A**\***mod**\***b**\***\+**\***B**\***mod**\***b**\***\)mod**\***b\*\*\*

**\(\*\*\***A**\***×**\***B**\***\)mod**\***b**\***=\(\(**\***A**\***mod**\***b**\***\)×\(**\***B**\***mod**\***b**\***\)\)mod**\***b\*\*\*

给每一部加上mod p便可以防止数过大而超过long long的数据范围。

```C++
        bl[cur] = true;

        for (auto& x : v[cur]) {

                }

                        b.push_back({cur,r[tar]});
                        dfs(r[tar]);
                }
        }
}

                e[b]++;
```
